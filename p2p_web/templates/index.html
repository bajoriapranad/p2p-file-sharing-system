ℹ️ Bluetooth Classic RFCOMM Prerequisites & Limitations

1. Windows Native Stack:

This application uses native Windows Winsock RFCOMM sockets (AF_BTH). It operates entirely peer-to-peer without internet, Wi-Fi router, or hotspot.

2. Pairing Requirement:

Bluetooth Classic requires the two devices to be paired in Windows Settings > Bluetooth & devices before a socket connection can be established.

3. Remote Device Service:

The receiving laptop must start the RFCOMM listener service. Stock phones (like Android or iPhone) do not expose an open RFCOMM server for this protocol unless a custom companion client is running.

4. Simulated Loopback Mode:

When a second Windows laptop is not physically present, the "Simulation / Loopback Mode" can be toggled to validate framing, chunking, and SHA-256 integrity verification locally.
